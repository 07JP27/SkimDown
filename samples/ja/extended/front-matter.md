# YAML フロントマター

SkimDown はファイル先頭の YAML フロントマターを、Markdown 本文の前にメタデータ表として表示します。

ファイルの先頭にあるフロントマターだけがメタデータとして扱われます。本文中の区切り線は通常の Markdown として表示されます。

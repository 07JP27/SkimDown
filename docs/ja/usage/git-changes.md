# Git差分表示

開いたフォルダがGit作業ツリーのルートの場合、最後のコミットからの変更を色分けして表示できます。

## オンにする

`View > Show Git Changes`（`Shift+Cmd+D`）を選びます。初期値はオフで、設定はすべてのウィンドウに共通し、自動で保存されます。

## 比較対象

現在のファイルを `HEAD` と比較します。ステージしたかどうかに関係なく、コミットしていない変更をすべて表示します。

開いたフォルダ自体が作業ツリーのルートである（直下に `.git` がある）必要があります。`.git` がファイルになっているリンクされたworktreeやサブモジュールにも対応します。リポジトリのサブフォルダを開いた場合は表示しません。

## プレビュー

変更があったブロックは背景をうっすら色付けし、本文の左側の余白に色付きのバーを表示します。バーはブロックの種類やリストの深さに関係なく同じ列にそろい、同じ種類の変更が続くブロックは 1 本のバーでつながります。

- 緑: 追加されたブロック
- 黄: 変更されたブロック
- 赤のマーカー: 削除された行

段落、見出し、リスト項目、表の行、コードブロック、水平線、HTMLブロック、front matter、Mermaid、数式はブロック単位で色分けします。単語単位の差分は表示しません。

行を削除した位置には赤い `N lines deleted` マーカーを、変更したブロックの直前には黄色の `Show previous version` マーカーを表示します。マーカーをクリックすると、変更前のMarkdownテキストを展開します。このテキストはそのまま表示され、本文検索の対象にはなりません。

`HEAD` にないファイルは全体を追加として表示します。`.gitignore` で無視されているファイルは色分けしません。

## サイドバー

VS Codeに近い表示で変更を示します。

- `M` と黄色のファイル名: 変更あり
- `U` と緑のファイル名: 未追跡
- `A` と緑のファイル名: インデックスに追加済みで未コミット
- 色付きの点: 変更を含むフォルダ

ファイルを単体で開いた場合、サイドバーの表示はありません。親フォルダが作業ツリーのルートであれば、プレビューは色分けします。

## 自動更新

Markdownファイルが変わったときと、コミット、ステージ、ブランチ切り替えで `HEAD`、ref、インデックスが変わったときに表示を更新します。

## 必要なもの

Xcode Command Line Toolsに含まれるシステムの `git` を読み取り専用で実行します。インストールされていない場合、Git差分は表示されず、プレビューは通常どおり動作します。詳しくは[プライバシーと権限](../security.md)を参照してください。
